
# 🧩 Pattern Making in C++

Welcome to the **Pattern Making in C++** repository! This project contains C++ programs that generate interesting and creative text-based patterns. The main focus is on two patterns: the **Dabbang Pattern** and the **Pyramid Pattern**. These patterns are commonly used in coding exercises and interviews to practice loops and logic-building.

## 🚀 Patterns Included

### 1. Dabbang Pattern

The **Dabbang Pattern** is a unique number-based pattern often seen in programming challenges. Here's a sample output:

```
5 4 3 2 1
5 4 3 2
5 4 3
5 4
5
```

To generate this pattern, run the `dabbangpattern.cpp` file.

### 2. Pyramid Pattern

The **Pyramid Pattern** is a classic pattern where stars or numbers are printed in a pyramid shape. Here’s a sample of what it looks like:

```
    *
   ***
  *****
 *******
*********
```

You can generate this pattern by running the `pyramid.cpp` file.

## 🛠️ How to Run the Programs

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/pattern-making.git
   ```

2. Navigate to the project directory:
   ```bash
   cd pattern-making
   ```

3. Compile and run the C++ programs:

   For **Dabbang Pattern**:
   ```bash
   g++ dabbangpattern.cpp -o dabbangpattern
   ./dabbangpattern
   ```

   For **Pyramid Pattern**:
   ```bash
   g++ pyramid.cpp -o pyramid
   ./pyramid
   ```

## 🧠 What You Will Learn

- **Nested Loops**: These patterns use nested loops to print rows and columns in a structured manner.
- **Conditionals**: Learn how to apply conditional logic to control the pattern output.
- **Logic Building**: Enhance your problem-solving skills by understanding how each line in the pattern is formed.
